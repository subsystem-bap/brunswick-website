# Brunswick website

Duncan Underwood’s portfolio of selected work in service design, digital experience and design leadership.

## Live website

https://duncan-underwood-portfolio.adoredlyric4.chatgpt.site

Public sharing was approved by Duncan on 13 October 2026. This repository contains the website source; the live website is hosted on Sites.

## Site structure

- `index.html`: page structure, experience, approach and contact information.
- `styles.css`: responsive layout, styling and print support.
- `app.js`: project content, filters, project dialogs and navigation.
- `favicon.svg`: site icon.

The site requires no build step or dependencies. Serve the repository root with any static web server. All asset paths are relative, so the site also works under a GitHub Pages project path.

## GitHub Pages

To host a second copy on GitHub Pages, open Settings → Pages, choose **Deploy from a branch**, and select **main / (root)**. The `.nojekyll` file allows the static files to be served directly. This is a repository administration setting and is not configured by this source upload.

## Content and privacy

Professional claims are based on Duncan’s supplied CV. Project visuals are abstract illustrations rather than screenshots of client work. No analytics or third-party font services are included. The `noindex` directive expresses a search-engine indexing preference; the public site and source are accessible to everyone.
